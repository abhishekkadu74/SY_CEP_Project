# SY CEP Project

A research and portfolio website created as a collaborative student project.

## Overview

This project presents research work, team contributions, and portfolio content in a structured multi-page website. Abhishek Kadu contributed as Team Leader.

## Features

- Research and portfolio landing page
- Dedicated pages for project content
- Blog and article sections
- Reusable assets and static page structure
- Responsive presentation for web visitors

## Built with

- HTML
- CSS
- JavaScript

## Project structure

- `index.html` - Main landing page
- `pages/` - Supporting website pages
- `blogs/` - Blog and research content
- `assets/` - Images and static resources
